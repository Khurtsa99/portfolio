# 👾 Хурцболдын пиксел портфолио

SWE334 Интернет програмчлал · Бие даалт 2: хувийн портфолио вэбсайт.

🔗 **Сайт:** https://ТАНЫ-САЙТ.vercel.app
🐙 **Репозитори:** https://github.com/Khurtsa99/ТАНЫ-РЕПО

## Бүтээлч санаа

Сайт нь 8-bit тоглоомын ертөнц шиг **пиксел өрөө** юм. Энгийн доош гүйлгэдэг хуудас биш:

0. **Интро:** том 3D маягийн нэр гарч, жижиг пиксел дүр дээрээс унаж ирнэ.
1. **Өрөө:** бүтэн дэлгэцийн пиксел өрөө. Зүүн доод буланд миний дүр яриа бөмбөлгөөр мэндэлнэ. Зочин эд зүйлс дээр дарж өрөөг судална.
2. **Zoom:** доош гүйлгэхэд камер ширээн дээрх компьютерын дэлгэц рүү ойртож, дотор нь «орно».
3. **Компьютер дотор:** Бүтээлүүд (3D carousel), Тоглоом, Холбоо барих, Терминал хэсгүүд бүтэн дэлгэцийн слайд болж, пиксел шилжилтээр солигдоно.
4. **Миний тухай:** өрөөний хананд байгаа хаалгыг дарахад хаалга онгойж, гэрэл тусаад тусдаа, тайван хуудас руу орно.

Өрөөн доторх зүйлс:

| Өрөөн доторх зүйл | Нээгдэх хэсэг |
|---|---|
| 💻 Компьютер | Бүтээлүүд (дэлгэц рүү орно) |
| 🚪 Хаалга | Миний тухай (хаалгаар орно) |
| 📱 Утас | Холбоо барих |
| 🌃 Цонх | Шөнө од харвана, өдөр шувууд нисэнэ |
| 🕐 Цаг | Улаанбаатарын одоогийн цаг |
| 🐱 Муур, 🙋 би | Easter egg |

Өрөөг бүхэлд нь SVG `<rect>` элементүүдээр пиксел бүрээр нь гараар зурсан. Гадны зураг огт ашиглаагүй.

## Онцлогууд

- 🎥 **Scroll zoom:** хулганы дугуй эсвэл хуруугаар гүйлгэхэд камер дэлгэц рүү ойртоно (CSS transform + requestAnimationFrame)
- 🖥️ **Слайдууд:** пиксел шилжилт, доод dock цэс, сум товч, Esc-ээр өрөө рүү буцна
- 📺 **Хуучны зурагт маягийн бүтээлүүд:** бүтэн дэлгэцэнд голд нь том CRT зурагт, хоёр захад өмнөх/дараагийн төсөл. Доош гүйлгэхэд суваг солих шиг шуугиантайгаар дараагийн төсөл гарна (canvas-аар үүсгэсэн noise, CSS perspective, rotateY)
- 🧍 **Хөтөч дүр:** зүүн доод булангийн дүр дээр дарахад өөр өөр зөвлөгөө хэлнэ, ✕-оор бөмбөлгийг хааж болно
- ✍️ **Тодорч гарах танилцуулга:** «Миний тухай» хуудсыг гүйлгэх тусам том налуу өгүүлбэр үг үгээрээ тодорно
- 🙋 **«Миний тухай» тусдаа хуудас:** пиксел биш, тайван загвартай намтар, ур чадвар, «хийх зүйлс» жагсаалт
- 🇲🇳 **Монгол өрөө:** цонхоор Богд уул, Зайсан толгой, Blue Sky цамхагтай Улаанбаатар харагдана. 
- 🌗 **Dark mode:** баруун дээд булангийн товч 3 горимтой: 🕐 Авто (Улаанбаатарын цагаар) → ☀ Light → ☾ Dark mode
- 🕐 **Улаанбаатарын жинхэнэ цаг:** 07–19 цагт өдрийн, бусад үед шөнийн өрөө автоматаар гарна. Ханын цаг жинхэнэ цагийг заана. 11–3-р сард цонхоор цас орно
- ⌨️ **Терминал:** компьютер дотор `help`, `whoami`, `projects`, `skills`, `coffee` гэх мэт командтай терминал. Tab-аар гүйцээж, ↑-аар өмнөх командыг дуудна
- 🐱 **Амьд муур:** өдөр шалаар алхаж, ханан дээрх шатаар үсэрч тоглоно. Шөнө (эсвэл Dark mode асаахад) орондоо очиж унтана, өглөө нь босно. Нүд нь хулганы заагчийг дагана, унтаж байхад нь дарвал сэрнэ
- 🎵 **Арын хөгжим:** Web Audio API-аар кодоор үүсгэсэн тайван lofi ая (файлгүй, зохиогчийн эрхгүй)
- 🪪 **Профайл карт ба цэс:** профайл карт үргэлж харагдана, цэс зөвхөн компьютер дотор гарна
- 🔍 **Нууцлаг өрөө:** өрөөн доторх 7 зүйл дээр хулганаар очиход зөөлөн гэрэлтэж, дарахад өөр өөр зүйл болно
- 🐛 **«Алдаа агнуур» мини тоглоом:** 20 секундэд алдаануудыг дарна. Хурд нь аажмаар нэмэгдэж, рекорд localStorage-д хадгалагдана
- 🌙 **Өдөр / шөнө горим:** өрөөний өнгө, цонхны тэнгэр, гэрэл бүгд өөрчлөгдөнө
- 🔊 **8-bit дуу:** Web Audio API-аар кодоор үүсгэсэн, ямар ч дууны файлгүй
- ⌨️ **Easter egg:** гар дээр «hello» гэж бичихэд солонго горим асна. Дахин «hello», Esc эсвэл дээрх тэмдэг дээр дарвал буцна
- 📱 **Responsive:** компьютер, таблет, гар утсанд тохирно
- ♿ Өрөөний зүйлсийг гараар (Tab + Enter) удирдаж болно. `prefers-reduced-motion`-ийг дэмжинэ

## Технологи

- **HTML5:** бүтэц, inline SVG пиксел зураг
- **CSS3:** CSS хувьсагч (горим солих), Grid/Flexbox, анимэйшн, media query
- **JavaScript (vanilla):** DOM, Web Audio API, Canvas (төслийн зураг), IntersectionObserver, localStorage
- **Байршуулалт:** Vercel

Фреймворк, сан ашиглаагүй. Бүх кодыг гараар бичсэн.

## Файлын бүтэц

```
index.html   – хуудасны бүтэц, пиксел өрөөний SVG
style.css    – загвар, өнгө, анимэйшн, responsive
script.js    – өрөөний харилцан үйлдэл, дуу, тоглоом, амжилтууд
README.md
```

## Ажиллуулах

`index.html` файлыг хөтөч дээр нээхэд л хангалттай. Эсвэл:

```bash
npx serve .
```
